# 内容语言维护

## 改哪里

| 需求 | 入口 |
| --- | --- |
| 翻译提示词、主题文案、说明标题 | `shared/i18n/<语言码>.ts` |
| 添加可选择的语言 | `shared/locales.ts` 中的 `LOCALES` |
| 修改回退顺序、语言码规则 | `shared/locales.ts` |
| 读取素材的标题、分类、标签、简介 | `shared/contentLocale.ts` |
| 读取原始或分主题思路 | `shared/prompt.ts` |
| 页面同步语言偏好 | `useContentLocale()` |
| 语言切换控件 | `LanguageControl`；顶栏语言菜单分别设置界面与内容语言，详情和整理用 `ContentLanguage` 提供就地切换 |
| 分类、标签的译名维护弹窗 | `TranslationEditor`：搜索语言、单语言编辑、填写状态 |
| 添加素材内容语言 | `LanguagePicker`、`src/lib/languageOptions.ts`：标准语言名称搜索，地区代码为高级入口 |
| 素材文案 | `texts.<语言码>`；分类、标签译名用 `labels.<语言码>` |

## 添加一种语言

1. 复制 `shared/i18n/en.ts` 为新语言文件，保留 `LocaleInfo` 类型，修改 `id`、短标签 `label`、语言名 `name`、方向 `direction` 和全部文案。可声明 `fallback: 'en'`。不要把未翻译的英文标成已支持的语言。
2. 在 `shared/locales.ts` 导入并加入 `LOCALES`。界面选择器、编辑入口、设置和提示词导出读取同一份注册表，无需逐页修改。
3. 按需给素材补 `texts.fr`、`labels.fr` 或 `idea.fr.md`。旧素材可保持原样；应用不会自动翻译或改写源码。
4. 运行 `npm run typecheck`、`npm test`、`npm run build`，检查长标签、缺译文、手机布局及 RTL 文本。超过三种语言时选择器自动使用下拉。

类型检查负责语言包必填项；`tests/i18n.test.ts` 检查注册表、回退、说明译文与控件，并阻止页面重新出现中英二选一判断。数据往返测试在 `tests/contentLocale.test.ts`。

## 回退与边界

- 使用 BCP 47 语言码，如 `fr`、`pt-BR`、`zh-Hant`、`es-419`。输入统一规范大小写；非法码拒绝写入。
- 语言包：精确语言 → 父级语言 → 注册的回退 → 默认英文。缺语言包只代表生成文案采用回退，不代表素材文案不存在。
- 素材标题、分类和标签：精确语言 → 父级语言 → 原始名称，保持稳定 ID 与筛选关联。
- 简介和思路：精确语言 → 父级语言 → 配置回退 → 英文 → 按语言码排序的其他已有内容。分主题思路在同语言中优先，否则使用该语言原始思路，不先跳去其他语言。
- 注释支持 `Original | zh: 中文 | fr: Français | es-419: Español`。先取同语言或父级译文，缺失时保留原文。
- 未安装语言包的合法文案也可保存、搜索和导入导出，编辑页会列出已有文案的语言。旧客户端保存时保留未提交的外部语言；明确提交空白文案可清除该语言。
- 译名维护使用固定高度语言列表和一个编辑区，不按语言数量堆叠输入框。切换、搜索不清除草稿；添加内容语言不等于安装应用语言包，保存仍由调用页统一提交。
- 添加语言按中文名、英文名、本地名称或代码搜索，标准清单复用 `iso-639-1`，名称展示沿用 `localeName`。不在页面手写语言选项表；地区和自定义语言码仍用 `normalizeLocale` 校验。填写状态不是启用开关。
- CEA 导航与操作界面使用独立的 i18next 实例，英文文案放在 `shared/i18n/ui/en.ts`，中文保留原始文案作为键。`uiText` 处理插值，组件用 `useUi` 订阅语言切换；不翻译用户输入、代码或素材原文。界面语言使用 `PREF_UI_LOCALE`（`cea:ui:locale`），配置 v2 的 `ui.locale` 可独立迁移。
- 内容语言仍使用 `PREF_LOCALE`（`cea:locale`），只影响素材展示、提示词和说明；源码内文字独立。界面语言变化不触发素材预览重载，也不更改内容语言。
- 本结构服务现有内容翻译，不自行处理自然语言复数、日期格式或自动翻译。将来需要这些能力时使用成熟 i18n 库，不在页面拼接句子实现。

## 给 AI 的维护要求

新增语言只扩展语言包与注册表；复用现有读取和切换入口。不要增加 `locale === 'zh' ? ... : ...`，不要按已安装语言列表过滤用户文案，不要为添加语言修改数据库列或批量重写素材。内置样例与旧版导入中的固定语言是来源事实，不是通用回退规则。
