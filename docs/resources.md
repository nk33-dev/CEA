# 源码与资源

每个框架目录是一份可交付实现：业务源码、资源原文件和依赖声明。预览打包结果只存在服务端缓存，不回写素材源码。

## 保存方式

- `Variant.files` 只包含文本源码。
- `Variant.resources` 只包含相对路径、MIME 和字节数，不携带 Base64。
- 资源保存在 `assets/<id>/code/<framework>/` 内，数据库的 `resource` 文件索引与 `code`、截图 `media` 分开。
- 文件夹导入按类型识别图片、字体、音视频和模型文件。导入服务在写入时传递原始字节，不经过 UTF-8 解码。
- 编辑保存会保留资源；旧客户端没有提交资源字段时也保留。明确传入空清单才移除该实现的资源。

## 预览

React、Vue 和 HTML 模块复用 Rolldown。资源 import 编译为相对地址，CSS 的资源路径按原样式文件所在目录解析。HTML 普通脚本继续使用 `script.js`；`script.mjs` 是可选模块入口，可以导入本地模块和 npm 包。

`/play/<id>/<framework>/<path>` 只提供已索引到该实现的文件，资源请求不读取整份素材源码。资源响应保留原字节并支持条件缓存。编辑草稿仅引用对应已保存素材的资源，不把资源编码进草稿请求。

预览 iframe 保持无同源权限的沙箱。本地图片需要以匿名 CORS 请求加载，才能用于 Canvas 像素读取和 WebGL 纹理；资源响应沿用 `Access-Control-Allow-Origin: *`。生成播放页时通过 HTML 解析器为本地 `img src` 补充 `crossorigin`，运行时同样处理 `new Image()`、属性赋值和动态插入的图片。仅处理当前播放目录中的资源，不覆盖素材显式指定的跨域模式或外链图片设置，不回写素材源码，也不改变复制和导出的内容。

依赖优先从当前素材库的 `.runtime/node_modules` 解析，未安装的包回退到 CEA 程序目录。React、React DOM 和 Vue 始终使用 CEA 的同一运行实例，避免插件依赖带入第二份框架。素材依赖不会进入 CEA 的前端应用包。

素材库的 `.runtime/package.json` 与锁文件记录本机预览依赖；程序不会自动安装依赖或执行素材提供的安装脚本。迁移素材库时，在 `.runtime` 内用 `npm ci --ignore-scripts` 恢复运行环境。素材导出保留每个实现的依赖声明，不打包 `node_modules`。

## 独立预览示例

`Variant.entry` 是交给项目使用的组件入口；可选的 `previewEntry` 是预览时挂载的示例入口。没有声明时继续使用 `entry`。示例导入原组件并提供 props、图片和内容，不把演示数据固化到组件内部。复刻提示词单独说明两个入口的职责；`data-demo-only` 继续只标记额外的演示控件，不标记整棵业务组件树。

保存、草稿和导入导出都保留两个入口。文件夹格式在 `asset.json` 中使用 `previewEntry: { "react": "Preview.tsx" }`；v6 及以后的备份保存这一声明。源码区仍能查看完整文件，复刻提示词说明示例部分的集成边界。

## 复制与导出

复制复刻提示词包含依赖、资源清单和完整文本源码。资源区可以下载参考包，提示词明确说明附件缺失时先索取原文件。

多文件 HTML 的源码按文件列出，保留模块和相对引用；简单 HTML 继续生成单页。参考包的 `source.html` 指向 `code/html/` 内的原文件，含 npm import 的实现通过目标项目的开发服务器运行。

参考包、文件夹导出和完整备份都包含原资源与依赖信息。v1–v6 备份仍可导入。不会静默删除旧源码中的内联图片或第三方库，旧素材是否整理由使用者决定。

## 回收站

浏览和整理中的删除只记录 `deletedAt`，保留代码、资源和截图。回收站支持搜索、批量恢复与永久删除；永久删除需要再次确认，随后移除数据库记录和对应素材目录。重复发送普通删除请求不会升级为永久删除。

v7 完整备份与全库文件夹导出包含回收站和删除时间，导入后保留删除状态。导入时明确选择覆盖同一 ID，仍按替换处理，不额外生成回收站副本。

## 验证

`tests/resources.test.ts` 使用合成二进制检查导入、编辑保留、资源隔离、条件缓存、草稿、依赖打包和三种导出的无损往返。测试不读取真实素材库。
