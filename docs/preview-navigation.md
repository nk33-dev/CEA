# 预览导航

缩放、鼠标拖拽、触控缩放、滚轮平移和位置边界由 `react-zoom-pan-pinch` 管理。`DevicePreview` 负责设备真实视口、旋转外壳、内容边界和已有工具栏的对接，不再维护另一套手势坐标或缩放动画。

`server/previewNavigation.ts` 是 iframe 适配：内部有可滚动内容时优先原生滚动；滚动容器在对应方向声明 `overscroll-behavior: contain` 或 `none` 时，到达边界后仍保留原生滚动隔离。未声明隔离、内部不能继续滚动且画布可平移时，把滚轮消息交给外层库。Ctrl / Meta + 滚轮交给库缩放。来源必须是当前预览的 iframe，消息数值必须有限。

文档根节点的 `overflow: hidden/clip` 不作为原生滚轮接收者。组件布局已完整处于 iframe 视口内时，舞台末尾 padding 不单独生成文档滚动条；真实内容超出视口时保留文档滚动，组件内部的独立滚动区不受影响。素材的 FLIP 临时变换越出自身边界时应在素材端约束，不能根据临时 `scrollHeight` 调整整个预览尺寸。

内容边界同时观察 body 和实际组件边界节点。组件变高但 body 仍被视口最小高度撑住时，仍需更新边界，供显式「完整显示」和画布边界使用；更新边界不自动改变播放中的倍率。

组件模式在 iframe 内保持顶部布局锚点，由宿主居中取景；不让内部高度动画触发整页垂直居中，再通过跨帧消息抵消。文字稳定性回归同时检查 iframe 内坐标和屏幕像素，不只检查 `.device-stage` 的 transform。

内容边界消息同时携带测量时的视口宽高和 framing。切换设备时，旧布局的边界不参与新视图的适应计算；等待匹配当前视口的测量后再取景。播放页在 resize 时重新报告，即使组件尺寸未变、只是居中位置改变也会同步。

鼠标点击和输入不自动平移画布。键盘导航到裁切区域外的控件时，使用库的 `panBy` 显示控件；裁切容器使用 `overflow: clip`，避免浏览器额外改变隐藏的滚动偏移。

`DevicePreview` 将画布可见范围反算到 iframe 坐标，通过 `cea:visible-area` 同步给播放页；列表由 `FitStage` 提供同一消息。原生 Popover 在这个范围内限制尺寸并保留原生滚动，测量不包含入场 transform，关闭后恢复素材样式。弹层不参与组件内容边界计算。

首次定位从 `beforetoggle` 安排到下一次原生绘制回调：此时弹层已经进入 top layer，但首帧还没有画出。`toggle` 可能晚于首帧，不能用来首次限制高度和修正位置。列表缩略图与详情分别验证，避免只有完整视口正常、受裁切的卡片仍在展开时跳动。独立合成数据回归见 `popover-first-paint.browser.ts`，天气列表回归见 `weather-thumbnail.browser.ts`。

播放页只给打开的 Popover 设置 `will-change: transform`，避免缩放 iframe 中的弹层文字反复重绘出重影。关闭后恢复默认，不给所有控件常驻图层。`weather-stability.browser.ts` 对菜单连续截图做像素对比，补充坐标和透明度检查。

编辑 Tab 隐藏时暂停库的尺寸观察，恢复时以当前尺寸重新观察，避免 `display:none` 的零尺寸改变预览位置。

组件、电脑和手机切换直接采用目标外壳与视口，不混合手机和电脑的外壳底色、阴影，也不对整层 iframe 额外淡入。旋转仍保留自己的 transform 过渡。预览播放控制只管理现有动效，不要求交互型素材自动触发业务状态。

工具栏动作：

- 移动画布：开启后由库接管拖拽，临时不接收 iframe 内的点击；关闭后恢复组件互动。按住空格也可临时移动。
- 回到中央：保留当前倍率，回到当前画面的中心。
- 完整显示：重算当前视图的适配倍率并居中。它是可重复执行的命令，不是开关。
- 组件内部动画或内容尺寸变化时保留外层倍率和画布位置，不逐帧重新适应；初次就绪、改变设备或工作区尺寸、再次执行完整显示时才重新取景。真实增长的内容仍可通过画布平移或组件内部滚动访问。
- 缩放输入：回车或失焦后应用，Escape 取消本次输入；点击百分号选择常用倍率。加减按钮拥有分开的点击区域，与预设入口保持间距。只聚焦输入框不会退出自动适应或改动比例。
- 全屏：入口与「适应」分开，组件按实际屏幕视口重新排版。工具栏默认隐藏，点击固定工具按钮展开，不通过悬停唤出。工具栏覆盖画面，不改变 iframe 尺寸。常规与全屏分别保存倍率；浏览器拒绝全屏时铺满窗口，Escape 或退出按钮返回，下拉和提示跟随当前全屏容器。

运行 `npm run test:browser -- preview-pan.browser.ts device-viewport.browser.ts device-switch.browser.ts`，验证放大、拖动边界、iframe 滚动、鼠标与键盘焦点、重复恢复视图，以及切换设备不重载。
