# 浏览与维护

- 有封面的素材先显示图片，操作预览时才加载运行页面；无封面素材在接近视口时加载。
- 同页最多保留 12 个最近使用的预览。离屏后暂停，预算以内回滚保留组件状态；超出预算或离开结果页时释放。
- 翻页保留旧列表直到响应到达，再替换结果并定位一次。筛选与排序不触发路由重复滚动。
- 预览边框、取景和缩放属于 CEA；素材本身的样式、主题和内容语言保持独立。
- 卡片可直接删除，批量管理支持导出、添加或移除标签、移动分类和删除。危险操作先确认，写入成功后才报告完成。
- 分类和标签显示中英译名，可筛选缺译项、按名称或使用量排序，点击使用量查看关联组件。改名、合并与译名仍使用原有稳定关联。
- 搜索覆盖名称、译名、简介、思路、来源、ID 和实现框架。未分类可单独筛选。

回归使用独立假数据。真实素材库的译名补充属于用户数据维护，不写成程序内置词表或迁移。
