# CEA · Craft Every Aspect

前端组件收藏与复用工具。卡片里直接运行组件，查看代码、复制提示词，独立管理分类标签与数据包。

## 运行

需要 Node.js 24 及以上（使用内置的 `node:sqlite`）。

```bash
npm install
npm run dev        # 开发：前端 http://127.0.0.1:5178，接口服务 5179
npm run build      # 构建前端
npm start          # 用构建产物运行：http://127.0.0.1:5180
npm test           # 数据层、复用内容、本地打包、迁移、导入导出测试
npm run test:browser # 启动构建版应用后验证浏览与交互；首次需 npx playwright install chromium
npm run cea -- guide | vocab | check <文件夹> | import <文件夹或 ZIP> [--overwrite] | export <位置> [id ...] | list | audit
```

首次启动使用空库，通过「添加组件」或「导入组件」加入自己的内容。程序仓库不附带收藏的组件源码、提示词或素材数据库。

## 找素材

首页顶部集中筛选，下方是素材网格：

- 服务端搜索名称、标签、各语言简介和思路提示词，多个词之间是「且」。每页 24 项，旧请求会在新查询发起时取消。`Ctrl K` 或 `/` 聚焦。
- 分类、框架单选；标签可以多选，选中的标签需要同时满足。每个选项后面的数字是加上它之后的结果数。
- 当前生效的筛选显示在结果上方，点一下就能去掉。卡片上的标签也能直接点来筛选。
- 筛选条件都在地址栏里，刷新、返回、收藏链接都能还原。
- 分类、框架、标签放在下拉里，选项多时可搜索；长列表只渲染可见选项。
- 视口附近的卡片直接加载，首段动画后休眠；悬停、键盘或触屏操作即可恢复。远离视口后卸载预览，显式播放同时只保留一个，暂停和重播按钮位于预览区外。
- 「批量管理」支持跨页选择、导出、添加标签、移动分类和删除。「整理」独立管理分类与标签，支持筛选后批量删除及合并标签。

## 三种复用内容

详情页右侧，都由 `shared/prompt.ts` 从素材本身生成：

| 标签 | 内容 | 切换 |
| --- | --- | --- |
| 源码 | HTML 实现合成一个完整的单文件页面；React / Vue 按文件列出 | 框架 |
| 复刻提示词 | 简短集成要求 + 完整代码；来源和简介留在素材信息里 | 框架、语言 |
| 思路提示词 | 可直接发给 AI 的简短需求：一句画面描述加少量关键交互；技术栈按需指定，不含代码 | 语言 |

语言只换复刻提示词的集成要求和思路提示词，代码不变；框架只换代码。上次选的框架和语言会记住，素材没有那个框架时用它的第一个实现。

需要代码参考时选择「复刻」或「源码」。「思路」只包含效果描述与目标配色要求，不附带代码，也不要求修改未提供的参考代码；目标配色不代表当前素材已支持该主题。

代码区先显示可读原文，再由 Worker 异步着色；长代码通过 TanStack Virtual 按可见范围渲染。超长文件和压缩依赖保持原文显示，按字符长度分块，复制和导出始终使用完整内容。详情初次只创建当前框架的预览，切换后保留访问过的实现；语言、组件主题和舞台背景切换不重载预览。

编辑页分为「代码与预览」「信息与提示词」两个 Tab。切换保留草稿、文件选择和设备状态，隐藏的预览暂停播放；返回时复用原 iframe 和最后有效尺寸。保存时先校验表单，未通过的字段会自动显示并获得焦点。

页面按路由加载，编辑、导入导出、设置等不进入首页启动链路；鼠标进入名称或键盘聚焦名称时预取详情模块，详情数据与页面模块并行加载。图标通过 Lucide 官方单图标入口引入，配置使用 Zod Mini，保持原有校验规则。日常使用可运行 `npm run build` 后执行 `npm start`，访问 `http://127.0.0.1:5180`；开发模式保留热更新和调试代码，冷启动开销更大。

预览工具栏提供暂停、继续和重播。暂停处理 CSS 动画、Web Animations、requestAnimationFrame 与音视频播放；组件自己的计时器、网络请求和业务数据不会被冻结。暂停状态在切换框架时保留，重播会恢复播放。暂停后点击或用键盘操作组件，会先恢复播放并同步工具栏，交互不会在被冻结的动画上继续运行。

预览缩放支持 25% 至 300%，可以直接输入百分比、点加减或还原。编辑页的「列表预览」单独维护缩略图比例，保存后用于浏览卡片；编辑页主预览和详情页的缩放都是临时调整，互不影响，不会写入源码或提示词。

大型组件可以选择宽幅（1200 × 720）或整页（1440 × 900）列表画布。列表在原始画布上渲染后等比缩小，宽幅组件跨两列展示，不触发手机断点。画布和列表缩放设置随备份、素材文件夹导入导出保留。

编辑页主预览与详情页使用同一套「电脑 / 手机」视口，内置仅提供默认电脑 1440 × 900、默认手机 390 × 844 CSS 像素。尺寸菜单可选择自己保存的预设，旁边的管理入口可输入宽高或比例、保存和移除预设；旋转按钮交换宽高。手机预览从页面顶部开始，超出屏幕的内容在 iframe 内滚动。面板较小时整体等比缩小；显示缩放不改变 iframe 的布局宽高，设备切换不重载 iframe。这里只模拟布局视口，字体渲染、浏览器内核、pointer/hover 和触摸输入仍由当前浏览器决定。

「设置 → 配置迁移」导出或导入 `cea-settings.json`，包含自定义尺寸预设、当前电脑/手机尺寸、默认代码框架、内容语言，以及独立预留的网站主题和界面语言偏好（切换入口尚未开放）。预览背景与组件主题为页面内临时状态，不随配置迁移。配置 v2 兼容 v1，旧预览配色不转换为网站主题；导入先校验格式与版本，再确认替换。不包含素材、草稿、素材库路径或最近打开的本机目录。换电脑时，素材备份和界面配置分别迁移。

播放页先完成字体和首帧绘制，再报告就绪并应用暂停状态；后台标签页停止动画。重播或更新代码时保留上一版画面，等新预览就绪后交接；超过 300ms 才出现小型加载指示，不遮盖已有内容。

详情页的「说明」从代码注释中提取许可、全局行为说明与动效参数。常见说明和参数支持中英文，原文保留；未知附注显示原文，不自动编造翻译。

参考包保留原始代码和提示词：`code/<框架>/`、`prompts/replica.<框架>.<语言>.md`、`prompts/idea.<语言>.md`；还提供带 `light`、`dark`、`both` 目标的复刻提示词及浅深色思路提示词。

## 添加素材

在 transitions.dev 组件页点 Copy prompt，到「添加素材」里粘贴，自动拆出名称、来源、英文简介和 HTML 代码。编辑页里可以再添加 React / Vue 实现，切换 EN / 中文填写简介和思路提示词。标签输入时会列出已有标签，只差大小写时沿用已有写法。

## 扩展

- **加框架**：在 `shared/frameworks.ts` 登记（入口文件、模板），再在 `server/bundler.ts` 的 `MOUNT` 里写挂载代码；需要编译的文件类型在 `load` 里处理。
- **加语言**：在 `shared/i18n/` 添加类型完整的语言包，并在 `shared/locales.ts` 注册；选择器、提示词、主题和说明复用统一入口。维护步骤及 AI 约定见 [内容语言维护](docs/i18n.md)。
- **加素材类型**：`assets.type` 已经预留了 `brand`（品牌配色与实现思路）、`guide`（设计思路）、`page`（整页参考）。它们沿用同一套结构：各语言文案 + 可选的代码实现 + 截图。打算的做法：
  - 品牌：思路提示词写配色、字体和气质；代码实现可以是一张展示色板和组件样例的 HTML 页面；可选增加一份结构化的色板（名称、色值、用途）。
  - 设计思路：只有文案和截图，复用面板只显示思路提示词。
  - 整页：和组件一样有实现，预览默认全屏尺寸。
  - 首页加类型筛选，卡片按类型换布局（色板、文字摘要或整页缩略图）。

## 统一约定

- **播放地址**：`/play/<id>/<框架>/`，不写框架时播放第一个实现。卡片缩略图、详情页预览、新标签页打开都用这个地址；编辑页的草稿走 `/play/~draft/<token>`。
- **素材 ID**：小写字母、数字和连字符，默认按名称生成（`Weather Day Switcher` → `weather-day-switcher`），同时是播放地址和素材目录名。
- **HTML 实现**固定三个文件：`markup.html`、`style.css`、`script.js`。
- **React / Vue 实现**的入口文件默认导出组件，可以 import 同目录的其他文件和 CSS；由本地的 rolldown 打包，离线也能预览。用到的第三方包需要先在程序里 `npm install`。
- **舞台**：预览工具栏的太阳 / 月亮选项只改变舞台背景。组件主题只按明确声明切换，AI 配色目标单独选择，三者互不联动。

## 主题与兼容

- 每种实现可选声明 `theme: { version: 1, mode: 'original' | 'light' | 'dark' | 'both', default: 'light' | 'dark' }`。固定浅色或深色不显示切换；双主题才显示切换；原始配色不注入主题属性。单主题的 default 与 mode 一致。
- 双主题通过组件自身的变量和规则改变前景、背景、边框与强调色，不依赖舞台变暗。配色变量限定在组件根节点，避免影响宿主页面。
- 复用面板单独选择「目标主题」。目标要求明确写进提示词；原始代码完整保留供 AI 参考，不自动删除分支。思路优先使用 `texts.<语言>.themeIdeas.light/dark`，未填写时保留原始思路并追加优先级明确的目标要求。
- 旧素材无需批量迁移：缺少声明时按原样播放，不自动注入主题或开放切换。代码识别结果供兼容审计使用，可在编辑页确认实际能力。旧客户端保存时保留遗漏的主题字段；明确传 `theme: null` 清除声明，`themeIdeas: {}` 清除分主题思路。维护边界见 [配色与预览](docs/themes.md)。
- `npm run cea -- audit [--json]` 只读列出声明与兼容状态，方便按需检查；不会重写素材。未知声明版本在写文件前拒绝，避免静默丢失数据。备份与文件夹导入导出均保留主题声明和分主题思路。

## 内容语言

浏览页和详情页共用内容语言偏好，标题、简介、分类、标签及提示词同步切换。界面导航语言和组件源码内的文字独立于内容语言。当前提供中文与英文语言包，可按统一注册表扩展；合法的其他语言文案也保留，不会因缺少语言包在导入时丢弃。

- 组件名称：编辑页「文案」下填写中英文名称，存入 `texts.<locale>.title`；默认名称 `title` 和素材 ID 保持稳定。
- 分类与标签：整理页的「编辑译名」维护 `labels.zh`、`labels.en`；筛选仍使用分类 ID 和标签原名，中英文名称都可搜索。
- 未填写译名时显示原名；简介和思路沿用已有语言回退。所有译名随完整备份、素材文件夹和参考包导出。
- 素材文件夹的 `asset.json` 使用 `titles`、`categoryLabels`、`tagLabels` 保存译名，完整示例见 `/guide`。

## 素材库目录

默认在 `E:\CEA-Assets`（没有 E 盘时为 `~/CEA-Assets`），和程序目录分开：

```
CEA-Assets/
  library.json            库标识
  library.db              SQLite：素材信息、分类、标签、各语言文案、文件索引
  assets/<素材 ID>/
    code/<框架>/          html/markup.html…、react/*.tsx、vue/*.vue
    media/                截图、录屏
```

数据库只存相对路径，程序和素材库都可以各自移动。旧版本的库打开时自动迁移。当前使用的库记在 `%APPDATA%\craft-every-aspect\config.json`。

指定素材库的方式，优先级从高到低：启动参数 `--library <目录>`、环境变量 `CEA_LIBRARY`、设置页里切换、默认目录。设置页通过本机目录浏览选择文件夹（也能粘贴路径），记住最近用过的库，可以直接在资源管理器里打开当前库。

程序目录只维护应用代码、文档和测试。测试使用临时目录与小型合成数据，不依赖个人素材库；浏览器中的真实素材交互回归需要单独准备测试库。素材库、备份 ZIP、数据库和本机配置不提交到程序仓库。

## 导入导出

两种格式：

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| 完整备份 | 一个 ZIP，`manifest.json` 带格式版本（当前为 4）、稳定 ID、各语言文案、主题声明、收藏和时间 | 换电脑原样恢复，可以恢复成一个新库 |
| 素材文件夹 | 每个组件一个文件夹：`asset.json`、`idea.<语言>.md`、`html/`、`react/`、`vue/`、`media/` | 自己整理、交给 AI 写或改，再导回来 |

素材文件夹格式的完整说明只有一份，在 `shared/folderGuide.ts`：`/guide` 页面、`npm run cea -- guide` 和导出文件夹里的 README.md 都用它。`asset.json` 可以带 `//` 注释。导入导出页和 `/guide` 页有一段给 AI 的导入说明：命令写成 `node "<程序目录>/server/cli.ts" … --library "<当前素材库>"`，AI 在哪个目录都能运行。路径按当前系统加引号（Windows 双引号，macOS / Linux 单引号），切换素材库后跟着变。页面上按步骤排版，复制出去是纯文本。只有一个 `index.html` 的文件夹会自动拆成三段；React / Vue 入口不写时按常见文件名或唯一的默认导出推断。

- 导入：拖入文件夹或 ZIP，或者通过本机目录浏览选择文件夹。先预览会导入哪些组件、哪些没认出来（附原因），重复的可以跳过、覆盖或另存副本。
- 导出：完整备份下载 ZIP；素材文件夹可以下载 ZIP，也可以直接写到本机某个文件夹。部分导出在首页「批量管理」里勾选。
- 命令行：`npm run cea -- check <文件夹>` 只检查不写入；`import <文件夹或 ZIP>` 导入，同 ID 已存在时跳过，加 `--overwrite` 覆盖、`--copy` 另存副本。有问题时返回非 0 并说明怎么改，AI 可以照着改到通过。程序运行时也能用，导入后刷新页面即可。不要直接改 `library.db`。
- 分类和标签：`guide` 末尾和 `vocab` 列出素材库已有的分类、标签（带中英文显示名和使用数）以及各框架用过的依赖，`list` 每个组件后面带分类和标签，`vocab`、`list` 加 `--json` 输出 JSON。导入素材文件夹时，写成已有词显示名的分类或标签（如「首屏」「Map」）归到那个词；新词照常新建，`check` / `import` 会列出新词、相近的已有词、和分类同名的标签以及缺少的译名，但不拦截。备份包按原样恢复，不做这一步。逻辑在 `server/transfer/vocabulary.ts`。

## 代码结构

```
shared/
  frameworks.ts      支持的框架
  locales.ts         内容语言与复刻提示词开头
  prompt.ts          三种复用内容的生成和解析
  types.ts、paths.ts 类型、路径与 ID 规则
  folderGuide.ts     素材文件夹格式说明（界面、导出的 README 和命令行共用）
server/
  db/schema.ts       建表与迁移
  db/repository.ts   全部 SQL
  library.ts         素材库目录、素材与文件管理
  play.ts            统一播放页
  bundler.ts         React / Vue 本地打包
  transfer/zip.ts    完整备份、参考包、导入校验与合并
  transfer/folder.ts 素材文件夹的识别与导出
  fsBrowse.ts        本机目录浏览、在资源管理器中打开
  cli.ts             命令行导入导出
  app.ts             HTTP 接口与路由
src/
  pages/             首页、详情、添加/编辑、导入导出、设置
  components/        卡片、舞台、复制按钮、对话框
  lib/               接口、偏好、代码着色、提示与弹窗
tests/
  helpers/library.ts 小型合成数据，仅供测试
```

修改类接口要求请求头 `x-cea-client: 1`，播放页里的素材代码带不上这个头，改不了素材库。
