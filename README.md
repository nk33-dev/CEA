# CEA · Craft Every Aspect

**打磨每一处细节，复用每一个好设计。**

CEA 是一个运行在本地的前端组件工作台，用来收藏、预览、学习和复用界面设计。

把喜欢的组件和交互收进来，直接查看效果、操作组件、阅读源码。需要用到自己的项目里时，可以复制代码，也可以把带源码的复刻提示词交给 AI；只想借鉴设计思路，就复制不含代码的思路提示词。

## 可以做什么

- **边看边试**：在浏览列表中悬停查看动效，打开详情后与组件互动。支持暂停、重播、缩放和拖动画布。
- **对照不同实现**：同一个组件可以保存 HTML、React 和 Vue 版本，切换查看代码与预览。
- **检查不同尺寸**：用电脑、手机视口查看布局，也可以自定义尺寸、保存预设。
- **整理收藏**：通过搜索、分类、标签和收藏找到组件，批量导出或调整分类标签。
- **保留自己的内容**：组件代码、说明和提示词保存在独立的本地素材库中，可以备份、导出，也可以迁移到另一台电脑。

## 开始使用

先安装 [Node.js 24 或更高版本](https://nodejs.org/)。

```bash
git clone https://github.com/nk33-dev/CEA.git
cd CEA
npm ci
npm run build
npm start
```

打开 [http://127.0.0.1:5180](http://127.0.0.1:5180)。

首次打开时，先选择素材库的位置：用空文件夹创建新库，或打开已有素材库。配置完成后，可以添加、导入自己的组件。仓库只提供程序，不附带组件收藏。

## 从收藏到复用

### 加入组件

可以直接录入代码，也可以导入组件文件夹或 ZIP。一个组件可以同时保存多个框架的实现，以及不同语言的名称、简介和思路提示词。

也可以在添加页粘贴 HTML 源码或带代码的复刻提示词，再检查、补全信息。来源名称和地址可以自由填写，方便记录作者、原项目或参考页面。

### 查看和学习

在详情中查看运行效果与源码，用手机或电脑尺寸检查布局。预览会按设定的视口宽高排版，但浏览器内核和输入方式仍来自当前电脑，不能替代真机测试。

舞台背景与组件配色分别控制：更换背景不会替组件生成暗色模式，只有声明支持双主题的实现才提供组件主题切换。

### 用到项目里

按需要选择一种内容复制：

| 内容 | 适合什么时候用 |
| --- | --- |
| 源码 | 想直接使用代码，或自己阅读、修改实现 |
| 复刻提示词 | 想让 AI 参考完整代码，按目标项目的技术栈改写 |
| 思路提示词 | 只借鉴画面和交互，让 AI 重新实现 |

提示词可以选择目标配色。这个选择只影响给 AI 的要求，不修改收藏的源码，也不代表当前组件已经支持该配色。

## 数据放在哪里

程序与素材库分开存放。素材库位置由你在首次使用时选择，之后可以在设置中切换。CEA 不预设磁盘或自动创建默认素材库。

素材库包含 SQLite 数据库、组件代码和媒体文件，不会随程序提交到 GitHub。程序更新和组件收藏各自管理。

换电脑时分别迁移两份内容：

- 在「导入导出」导出完整备份，到新电脑导入，恢复组件和整理信息。
- 在「设置 → 配置迁移」导出配置，保留自定义视口预设、默认框架和内容语言等偏好。

想把组件交给 AI 修改，可以导出为组件文件夹，改好后再导入。导入前会显示内容预览；遇到重复组件，可以跳过、覆盖或另存副本。
